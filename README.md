## 🚀 Hướng dẫn chạy dự án

### 1. Cài đặt và chạy Backend (Docker)
Đảm bảo bạn đã cài đặt **Docker Desktop** trên máy.

1. Di chuyển vào thư mục backend:
   ```bash
   cd backend
   docker compose up -d
2. Cài đặt và chạy Frontend
   ```bash
   cd frontend
   npm install
   npm run dev
